# GTR replay library

Gorilla Tag games recorded by GTR casters with the GTR casting mod, shared so **GTR Coach** can learn how good players run and tag.

* Each file (`.gtrt`) is **movement only**: positions, hands, who was it, tags and player names. There is no voice or sound.
* Files are attached to the monthly releases (`replays-2026-11`, ...). GTR Coach downloads them by itself.
* The index is at `https://api.gtr-org.org/api/v1/replays`.

Casters can turn sharing off in the casting mod (Elo Reports → share replays with GTR Coach).
